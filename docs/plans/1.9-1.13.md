## Decisions

- **The cheap refusals come first.** Validate, resolve the voice, then check quota, then
  look in the cache, and only then take a dispatch slot (FL-01). Everything before
  dispatch can refuse a request without costing the fleet anything.
- **A cache hit still bills** (US-11 AC-4). The tenant received the audio; cache
  economics are ours, not theirs (ADR-006).
- **Quota is recorded only for a delivered synthesis.** A worker failure leaves the
  allowance untouched, which a test pins.
- **A cache failure is never fatal.** A lookup error, an unreadable object or a failed
  store all fall through to synthesising, because re-synthesising is always correct —
  only slower.
- **Out-of-order frames abort the request** (US-09 AC-3). Returning audio we know is
  wrong would be worse than failing.
- **mp3 and ogg_opus are refused plainly**, naming task 2.2, because they need the
  worker's `Merge` RPC. Returning a WAV mislabelled as MP3 would be a lie the client
  discovers at playback.
- **Defaults live in the use case, not the handler**, so sync, stream, WebSocket and
  jobs agree on what an omitted field means — and two requests differing only in what
  they omitted produce the same cache key.
- **Text limits count characters, not bytes.** 3,000 Vietnamese characters is up to
  9,000 bytes; a byte limit would reject a request the contract allows.
- **The catalogue follows the fleet.** Voices are upserted from what ready workers
  advertise, so a model upgrade shows up without a migration and the database can never
  offer a voice no worker can produce.
- **A tenant asking for another tenant's voice gets `unknown_voice`**, not a permission
  error: the existence of another tenant's voice is not ours to disclose.

## Fixed while writing it

- **`text_too_long` was 400 and `unknown_voice` was 400.** US-08 AC-3 says 413 and 422,
  and the OpenAPI response list agrees. Both are now correct.
- **`Retry-After` had no way to reach a problem response.** `Error` now carries it, and
  the rate limiter's own header logic was folded into the same helper — one definition of
  "whole seconds, never zero".
- **gosec flagged seven integer conversions.** Each is now bounds-checked rather than
  suppressed; the three that remain carry a `nolint` naming the guard above them.
- **The gateway container was missing `VITTS_S3_*`**, so it refused to boot once the
  cache needed object storage. Compose now passes them and waits for the bucket to exist.

## Known gap

The voice catalogue is empty for up to `voiceSyncInterval` (60 s) after a cold start,
because the first sync runs before any worker is ready. `/v1/voices` returns an empty
list in that window rather than an error. Fixing it properly means syncing on the pool's
ready transition, which belongs with the metrics work in 3.1.
