## Decisions

- **Plan figures live in `config/plans.yaml`, not in a migration.** The file ships with
  placeholder numbers marked `TODO(pricing)`, `make seed` upserts them, and re-running it
  is how a limit changes. Migration 0001 still ships no plans, so nothing invented can
  reach production through a schema change.
- **Both limiters are Lua scripts.** Refill-test-consume and evict-count-insert must be
  atomic *across replicas*; doing them in Go would let two gateways admit the same last
  slot. T-05 hammers the bucket with 100 goroutines and asserts exactly `limit` pass.
- **An expired lease is evicted by the next caller**, not by a sweeper: the script drops
  everything scored below now before counting. A gateway that crashed therefore stops
  holding capacity within one TTL with no extra moving part (US-06 AC-3).
- **`Renew` reports a lost lease** instead of silently re-adding it. A stream whose lease
  was reclaimed must learn that and stop, rather than keep consuming capacity it no
  longer holds.
- **The rate limiter fails closed.** A Redis outage returns 500, not "allow": a limiter we
  cannot consult is not permission to ignore the limit, or one outage becomes an
  unbounded load test against the workers.
- **`Retry-After` is never 0.** It rounds up to whole seconds, because a 0 invites an
  immediate retry into the same refusal.
- **Quota `Check` consumes nothing.** The counter moves only in `Record`, after a
  successful synthesis, so a worker failure never bills the tenant (US-07 AC-2).
- **A zero allowance means metered, not blocked**, so the pay-as-you-go tier has no
  ceiling to hit.
- **Reconcile reads `synth_requests`**, the system of record, because `usage_daily`
  belongs to migration 0002. When that rollup exists it can replace the scan; the
  interface (`quota.UsageSource`) already hides which one is used.
- **Reconcile touches only tenants with activity this month.** Rewriting every tenant's
  key hourly would be work proportional to the customer base rather than to traffic.
- **Months are UTC.** A deployment that moves timezone must not give a tenant two resets
  or none.

## Fixed while writing it

- **`quota_exceeded` was mapped to 429; it is 402.** `FL-01` step 5 and US-07 AC-1 both
  say 402, and they are right: the tenant is out of allowance, not going too fast, and
  retrying without buying more will not help.
- **`depguard` caught a real layering violation**: `internal/quota` imported go-redis
  directly. The counter is now a port (`quota.Counter`) implemented in the Redis adapter.
  This is exactly what the rule was written for.
