## Decisions taken here

- **Three `buf lint` exceptions**, each with a reason in `proto/buf.yaml`:
  `PACKAGE_DIRECTORY_MATCH` (the contract path is fixed by ADR-009, not mirrored to
  `vitts/worker/v1/`), `SERVICE_SUFFIX` and `RPC_RESPONSE_STANDARD_NAME` (renaming
  `Worker` / `AudioFrame` would churn a contract that already has no callers, and
  `AudioFrame` names a stream element, not a response).
- **Go 1.23 → 1.25.** `grpc-go` and `protobuf` current releases no longer build under
  1.23. `docs/14-engineering-standards.md` and `docs/02-architecture.md` updated in this
  PR rather than pinning the stack to EOL dependencies.
