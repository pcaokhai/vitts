## Decisions

- **One goroutine reads the socket for its whole life.** In `coder/websocket`, cancelling
  a context mid-read closes the connection — so an utterance must never own the reader,
  or the first cancel would kill the socket instead of the utterance. The reader
  classifies frames and the utterance subscribes to what it finds.
- **Writes use the session context, not the utterance's.** Cancelling a write's context
  would close the socket, and surviving a cancel is the entire point of the endpoint.
- **A stale cancel is drained between utterances**, so a cancel that lands just after an
  utterance finished cannot abort the next one.
- **Errors are sent *and* logged.** An error a client can see but operations cannot is a
  blind spot — which is exactly how this endpoint's first bug stayed hidden for three
  debugging rounds.
- **The contract is embedded in the binary**, so what a client reads is the contract that
  build implements. `make generate` copies `docs/api/openapi.yaml` into `gateway/api/`
  and the drift check in CI keeps them identical (ADR-009).
- **A test asserts every emitted `Problem.code` exists in the contract's enum.** A code
  the API can return but the contract does not declare is unhandleable by a generated
  client.

## Found by running it, not by reading it

Three real defects, each invisible to unit tests:

1. **The logging middleware broke WebSocket upgrades.** Wrapping a `ResponseWriter` hides
   the interfaces it implements, so `http.Hijacker` was gone and every upgrade failed
   with an immediate EOF. `statusRecorder` now delegates `Hijack`.
2. **A worker can refuse a slot the pool advertised.** The health snapshot lags one poll,
   and the worker is the authority (ADR-003). `RESOURCE_EXHAUSTED` is now classified as
   overload rather than a broken worker, the header is written on the first audio frame
   rather than before it — so a refusal is a clean error instead of a truncated stream —
   and the request re-reserves up to three times with a 150 ms backoff, inside the
   class's existing budget.
3. **The worker took 735 ms to release a cancelled slot**, against the 200 ms US-01
   acceptance criterion 3 allows. Cancellation is checked between streamed chunks, and
   upstream's default chunk is 16 model frames. `STREAM_MAX_CHUNK_FRAMES = 4` brings it
   to **184 ms**, measured, at the cost of slightly more per-chunk overhead. T-02 passed
   throughout because it measures the engine generator, not the slot behind the servicer
   — the gap between those two is what this fixes.
