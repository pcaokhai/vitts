- **A2** (2×4 still beats real time): holds — RTF barely moves under contention, so a
  node can run two worker processes without either falling behind.
- **US-01 AC-2** (TTFA ≤ 150 ms): holds.

**A1 is only partly settled.** It is stated for Hetzner CCX / AWS c7i; this run is Apple
silicon, which is not that hardware. `make bench` must be re-run on the target host
before capacity planning depends on it. The PRD row says so rather than claiming the
assumption is closed.
