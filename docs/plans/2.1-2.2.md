## Decisions

- **Normalise before chunking, never after.** Normalising a segment would let a number
  expand across a boundary and change how that segment is read.
- **`chunk_text` is upstream's**, from `zerotts.chunking` (ADR-002 forbids reimplementing
  model-adjacent logic). It is not re-exported at the package's top level, which is why
  an earlier survey of `zerotts` concluded it did not exist.
- **Segmentation runs in a thread.** 100k characters of pure Python must not block the
  event loop that answers `Health`.
- **The worker reads and writes the objects itself.** The gateway never proxies segment
  audio, so a long job's bytes do not cross it twice.
- **A missing segment names its key** in the `FAILED_PRECONDITION` message: the
  orchestrator knows which segment failed to upload, and a generic error would not tell
  it (US-04 acceptance criterion 3).
- **libsndfile carries LAME and Opus**, so the worker needs no external encoder. Both are
  variable-bitrate, and the compression level is a 0..1 quality knob rather than a
  bitrate, so US-04's "64 kbps / 32 kbps" is approached, not pinned. Measured on real
  synthesized Vietnamese: **59 kbps MP3, 31 kbps Opus**.
- **A worker with no object storage refuses `Merge` plainly** rather than failing
  obscurely, because synthesis still works without it.
- **`jobs_active_idx` and `job_segments_pending_idx` are partial.** The orchestrator and
  the reconciler only ever scan live work; indexing completed jobs would grow forever for
  queries nothing runs.

## A measurement that misled

A first sweep used a synthetic tone plus noise and suggested compression levels of 0.65
and 0.75. On real speech those produced 35 kbps for both codecs — VBR encoders respond to
content, and a tone is not speech. The committed values (0.55 MP3, 0.90 Opus) were chosen
from the sweep and then **confirmed against audio the model actually produced**, which is
the only measurement that counts here.

than estimated.

## Out of scope

The jobs API (2.3), the orchestrator that drives these RPCs (2.4), webhooks (2.5). The
gateway still refuses mp3 and ogg_opus for sync and streaming requests: those paths would
need an S3 round trip per request, which is a different trade-off from a job's.
