# Data model

## 1. PostgreSQL (system of record)

Conventions: `uuid` PKs generated by app (UUIDv7 for time ordering), `timestamptz`
everywhere, `created_at`/`updated_at` on mutable tables, soft delete only where the
column exists, every tenant-owned table has `tenant_id` and every query filters on it.

```sql
create table plans (
  id                    text primary key,          -- free | starter | pro | payg
  chars_per_month       bigint not null,
  req_per_minute        int    not null,
  max_concurrent_streams int   not null,
  max_job_chars         int    not null default 100000,
  price_usd_cents       int    not null default 0,
  overage_usd_per_million numeric(8,2)
);

create table tenants (
  id          uuid primary key,
  plan_id     text not null references plans(id),
  name        text not null,
  status      text not null check (status in ('active','suspended','deleted')),
  created_at  timestamptz not null default now(),
  updated_at  timestamptz not null default now()
);

create table api_keys (
  id            uuid primary key,
  tenant_id     uuid not null references tenants(id),
  name          text not null,
  key_hash      bytea not null unique,        -- sha256(secret); secret has 256 bits entropy
  prefix        text not null,                -- 'zt_live_ab12cd34'
  scopes        text[] not null,
  store_text    boolean not null default false,
  created_at    timestamptz not null default now(),
  last_used_at  timestamptz,
  revoked_at    timestamptz
);
create index on api_keys (tenant_id) where revoked_at is null;

create table voices (
  id             text primary key,             -- maichi
  display_name   text not null,
  gender         text,
  tags           text[] not null default '{}',
  model_version  text not null,
  tenant_id      uuid references tenants(id),  -- null = public preset (F-15 ready)
  enabled        boolean not null default true
);

create table audio_cache (
  cache_key     bytea primary key,             -- sha256
  s3_key        text not null,
  format        text not null,                 -- pcm16_48k
  duration_ms   int  not null,
  bytes         bigint not null,
  hit_count     bigint not null default 0,
  created_at    timestamptz not null default now(),
  last_hit_at   timestamptz not null default now()
);
create index on audio_cache (last_hit_at);

create table synth_requests (
  id            uuid not null,
  tenant_id     uuid not null,
  api_key_id    uuid not null,
  voice_id      text not null,
  cache_key     bytea,
  mode          text not null check (mode in ('sync','stream','job_segment')),
  chars         int  not null,
  duration_ms   int,
  ttfa_ms       int,
  cached        boolean not null default false,
  status        text not null check (status in ('ok','client_cancelled','error','rejected')),
  error_code    text,
  request_text  bytea,                         -- encrypted, only when store_text=true (ADR-008)
  created_at    timestamptz not null default now(),
  primary key (id, created_at)
) partition by range (created_at);
create index on synth_requests (tenant_id, created_at desc);

create table jobs (
  id               uuid primary key,
  tenant_id        uuid not null references tenants(id),
  api_key_id       uuid not null,
  idempotency_key  text not null,
  status           text not null check (status in
                   ('queued','segmenting','synthesizing','merging','completed','failed','cancelled')),
  voice_id         text not null,
  format           text not null,
  sample_rate      int  not null,
  normalize        boolean not null,
  params           jsonb not null,
  total_chars      int  not null,
  segments_total   int,
  segments_done    int  not null default 0,
  output_s3_key    text,
  duration_ms      int,
  webhook_url      text,
  webhook_attempts int not null default 0,
  metadata         jsonb not null default '{}',
  error            text,
  created_at       timestamptz not null default now(),
  updated_at       timestamptz not null default now(),
  completed_at     timestamptz,
  unique (tenant_id, idempotency_key)
);
create index on jobs (tenant_id, created_at desc);
create index on jobs (status) where status in ('queued','segmenting','synthesizing','merging');

create table job_segments (
  id          uuid primary key,
  job_id      uuid not null references jobs(id) on delete cascade,
  seq         int  not null,
  text_hash   bytea not null,                  -- = cache_key when cached
  chars       int  not null,
  status      text not null check (status in ('pending','running','done','failed')),
  attempts    int  not null default 0,
  s3_key      text,
  last_error  text,
  unique (job_id, seq)
);

create table usage_daily (
  tenant_id   uuid not null,
  day         date not null,
  chars       bigint not null default 0,
  audio_ms    bigint not null default 0,
  requests    bigint not null default 0,
  cache_hits  bigint not null default 0,
  primary key (tenant_id, day)
);

create table audit_log (
  id          uuid primary key,
  actor       text not null,                   -- admin key id or tenant key id
  action      text not null,
  target      text,
  detail      jsonb,
  created_at  timestamptz not null default now()
);
```

Job text: stored in S3 at `jobs/{tenant_id}/{job_id}/input.txt` (server-side encrypted),
deleted when the job reaches a terminal state + 24 h. Never in Postgres.

### Schema notes (task 1.2)

- `plans` ships **empty**. Tier names, limits and prices are an open product decision;
  `scripts/seed.sql` inserts a placeholder `dev` plan for local work only.
- `synth_requests` partitions are created by `ensure_synth_requests_partition(at)`,
  defined in migration 0001 and called by the maintenance job (task 2.8). A month with
  no partition makes the insert fail rather than silently drop metering data.
- Migration 0001 adds `check` constraints the sketch above omits: name lengths,
  non-negative counters, and `octet_length(...) = 32` on `api_keys.key_hash` and
  `audio_cache.cache_key`.
- `jobs`, `job_segments` and `usage_daily` arrive in migration 0002 (task 2.1).

## 2. Redis keys

| Key | Type | TTL | Purpose |
|-----|------|-----|---------|
| `auth:{sha256(secret)}` | hash | 60 s | Cached key row (tenant, plan, scopes) |
| `rl:{key_id}` | Lua token bucket (2 fields) | rolling | Requests per minute |
| `conc:{tenant_id}` | set of lease ids | lease 60 s | Concurrent streams semaphore |
| `usage:{tenant_id}:{yyyymm}` | int | 40 d | Monthly chars for quota check |
| `cache:{hex(cache_key)}` | hash {s3_key,duration_ms,format} | 30 d sliding | Cache index |
| `jobs:pending` | stream | — | Job queue (consumer group `orchestrators`) |
| `jobs:segments` | stream | — | Segment work items |
| `idem:{tenant_id}:{key}` | string job_id | 24 h | Fast idempotency lookup |
| `worker:{addr}` | hash | 15 s | Last health snapshot |

All limiter operations are Lua scripts (`EVALSHA`) to stay atomic.

## 3. Object storage layout

```
cache/{first2(hex)}/{hex(cache_key)}.pcm     PCM16 48 kHz mono (canonical)
jobs/{tenant_id}/{job_id}/input.txt
jobs/{tenant_id}/{job_id}/seg/{seq:05}.pcm
jobs/{tenant_id}/{job_id}/output.{mp3|ogg|wav}
models/{model_version}/...                    mirror of HF weights
voices/previews/{voice_id}.mp3
```

Lifecycle rules: `jobs/*/input.txt` 2 days; `jobs/*/seg/*` 2 days; `jobs/*/output.*`
30 days; `cache/*` managed by eviction job (not lifecycle, because it depends on hits).

## 4. Consistency rules

- Quota is enforced from Redis; reconciled hourly from `usage_daily` (Redis is a cache of truth, not the truth).
- `synth_requests` inserts are idempotent on `id`; the meter may retry safely.
- Job state transitions use `update ... where id=$1 and status=$2`; zero rows affected = lost race, re-read and decide.
- `segments_done` is incremented by the same statement that marks a segment `done`.
