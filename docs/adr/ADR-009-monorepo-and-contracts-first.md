# ADR-009: Monorepo with contracts generated in CI

Status: Accepted

## Context
Two services, one contract each way (`openapi.yaml` public, `worker.proto` internal). Drift
between hand-written types and contracts is a classic failure.

## Decision
Single repository. `proto/` and `docs/api/openapi.yaml` are the sources of truth; Go and
Python stubs are generated by `make generate` and checked in; CI fails if regeneration
produces a diff.

## Consequences
One PR can change contract and both implementations atomically. Requires `buf`,
`oapi-codegen`, `grpcio-tools` in the dev container.
