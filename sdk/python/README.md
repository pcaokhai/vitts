```python
from vitts import JobCreateRequest, SynthesizeRequest, VittsClient, job_status

with VittsClient(api_key) as client:
    # One file.
    audio = client.synthesize(SynthesizeRequest(text="Xin chào.", voice="maichi"))

    # Or as it is produced. Ordering is guaranteed.
    for chunk in client.stream(SynthesizeRequest(text="Xin chào.")):
        play(chunk)

    # Long text runs as a job.
    job = client.create_job(JobCreateRequest(text=long_text, format="mp3"))
    done = client.wait_for_job(str(job.id))
    assert job_status(done) == "completed"
```

`AsyncVittsClient` has the same surface on asyncio, with `async for` over streams.

Errors carry the API's own code:

```python
from vitts import VittsError

try:
    client.synthesize(SynthesizeRequest(text=text))
except VittsError as error:
    if error.code == "quota_exceeded":
        ...  # out of allowance for the month
```

`vitts/models.py` is generated by `make generate`. Do not edit it; change
`docs/api/openapi.yaml` and regenerate.
