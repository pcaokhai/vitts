# @vitts/sdk

```bash
npm install ./sdk/js
```

```ts
import { VittsClient } from "@vitts/sdk";

const client = new VittsClient({ apiKey: process.env.VITTS_API_KEY! });

// One file.
const audio = await client.synthesize({ text: "Xin chào.", voice: "maichi" });

// Or as it is produced. Ordering is guaranteed.
for await (const chunk of client.stream({ text: "Xin chào." })) {
  play(chunk);
}

// Long text runs as a job.
const job = await client.createJob({ text: longText, format: "mp3" });
const done = await client.waitForJob(job.id!);
```

Cancel by passing an `AbortSignal`: the gateway stops the worker within 200 ms and bills
the audio delivered, not the text sent.

```ts
const stop = new AbortController();
setTimeout(() => stop.abort(), 500);
for await (const chunk of client.stream({ text }, stop.signal)) { /* … */ }
```

Errors carry the API's own code:

```ts
import { VittsError } from "@vitts/sdk";

try {
  await client.synthesize({ text });
} catch (error) {
  if (error instanceof VittsError && error.code === "quota_exceeded") {
    // out of allowance for the month
  }
}
```

`src/types.gen.ts` is generated by `make generate`. Do not edit it; change
`docs/api/openapi.yaml` and regenerate.
